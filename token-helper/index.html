ANTKSL · обновление VK-доступа

Страница нужна только для редких служебных операций. «Студийные истории» публикуются локальным движком напрямую.

1. Проверка прав — ничего не публикует

Выясняет главное: даёт ли токен мини-приложения право на wall.post. Проверка wall.post делается заведомо неполным запросом: если прав нет, VK ответит «доступ запрещён», если права есть — «не хватает параметров». Запись на стену при этом не создаётся ни в каком случае. 
Готов к проверке.

2. Выдать токен движку для VK-альбома

Публикация в альбом сообщества работает на этом же ключе: photos у мини-приложения действует. После нажатия кнопки ключ автоматически копируется в системный буфер через VK Bridge; VK_PHOTO_REFRESH_ONECLICK.bat на компьютере подхватит его сам. Если автокопирование недоступно, ключ всё равно будет показан ниже для ручного резервного сценария. Страница не отправляет ключ на сторонние адреса. Никому не пересылайте эту строку. 
Ключ появится здесь.

3. Обновление USER token

Запустите VK_USER_AUTH.bat на компьютере. Он сам скопирует одноразовый код подключения.
