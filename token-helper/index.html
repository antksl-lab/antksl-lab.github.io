ANTKSL · Студийные истории

Одна VK Mini App для двух задач. Для обычной публикации истории используйте верхний блок «Фотоальбом». Служебное обновление USER-token находится ниже.

РАБОЧИЙ МАРШРУТ

1. Студийные истории → фотоальбом

После запуска VK_ALBUM_BRIDGE.bat или кнопки «VK альбом (рабочий)» код подключения уже лежит в буфере обмена. Вставьте его сюда и подключитесь.
VK Bridge инициализируется…

2. Служебная проверка прав — ничего не публикует

Проверяет доступ Mini App к VK API. Этот блок не нужен для обычной альбомной публикации.
Готов к проверке.

3. Редкое обновление USER token

Используйте только если локальный движок прямо попросил запустить VK_USER_AUTH.bat.
